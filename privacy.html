Privacy & AI use

You choose what to share with Lia and which tests to publish. A public test does not require respondents to create an account.

Updated September 29, 2026

Your Lab account

For a Lab account, the private server stores your email, salted password hash, saved chats, onboarding answers, project memory, selected source summaries, missions, maturity evidence, and interest tests. An interest test stores its questions, settings, responses, optional comments, calculated results, and any saved Lia review. Signed-in chats save automatically. Guest drafts stay in your browser until you choose to save them to a Lab account. Account sessions use an HTTP-only cookie.

Connected sources

If account connectors are configured, Gmail, Google Drive, and Google Calendar request read-only access, and Notion access is limited to the pages you approve there. These connections are not configured for general visitors in this edition. You choose which available items to import and analyze. The demo does not send email, edit files or events, or change Notion pages.

OAuth access tokens, source lists, and raw imported content stay in temporary server memory and are not written to the Lab account store. Tokens expire or are removed when you disconnect, sign out, delete the account, or the server restarts. You can also revoke access in your Google or Notion account.

What goes to the AI

When you request Lia's analysis, the server sends the relevant request data to Crusoe Foundry Serverless Inference using a server-side API key. If Crusoe reports that its credits are exhausted, the server sends the same request through AdaL using the connected ChatGPT account. A chat request can include your message, limited recent conversation context, project memory, a pinned mission, and source summaries you selected. When you click Analyze for a file or source, selected extracted text is also sent. Local files are read in your browser; the original file is not saved by the demo server.

A visitor's answer to a public interest test is saved on this server and shown in the founder's private results. Submission does not itself call the AI. After the founder closes a test and asks Lia for a review, the server can send the test hypothesis, audience, question, calculated counts and threshold, and up to 25 optional response comments to Crusoe or, after a credit failure, AdaL. Do not put sensitive personal information in a response comment. A public test page shows the approved question and answer choices, not other people's responses or the founder's private project data.

Provider content is not added to a saved chat by merely connecting. An AI reply or saved source summary can still contain details from a selected source, so review the items you choose before analyzing them.

Your controls and demo limits

You can disconnect a source, remove a selected summary, delete chats, or delete your Lab account in the Account panel. Account deletion removes its stored project, maturity, interest-test and response data, and revokes its active Lab sessions. Guest browser drafts can be cleared in the browser. This demo may run locally or on a separate hosted Node service; Render with private persistent storage is the proposed host for this edition. Availability and long-term storage are not guaranteed.
